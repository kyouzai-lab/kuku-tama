# くくたま

小学2年生向け。九九を1回45秒（1日3回まで）解いて、たまごから生まれたキャラクターをお部屋で育てるWebアプリ。

- 学校のiPad（Safari・横画面）向け。縦でもくずれない
- 記録はそのiPadのブラウザの中だけに保存（サーバーなし・ログインなし）
- 仕様書・ワイヤーフレーム・見た目の見本は作者の手元にだけあり、このリポジトリには入れていない

## 起動（パソコンで試す）

ビルドは要りません。フォルダをそのまま配信するだけで動きます。

```
python -m http.server 8811
```

（このフォルダの中で実行する）

→ ブラウザで http://localhost:8811 を開く

## ためし用のオプション（URLのうしろにつける）

| つけるもの | できること |
|---|---|
| `?debug=1` | 左上に小さなボタン：あしたへ／回数もどす／けいけんち+50／たべもの+5／育つ条件にする（次のチャレンジのあとに育つ）／タイプ表示 |
| `?fast=1` | チャレンジが8秒になる（流れの確認用） |
| `?debug=1&fast=1` | 両方 |

子どもに配るURLには何もつけない。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 入れ物とフェルトの質感フィルター |
| `css/style.css` | 見た目（デザインシステムどおりの色・部品） |
| `js/main.js` | 画面（たまごえらび・なまえ・お部屋・だんえらび・チャレンジ・けっか・せいちょう・せってい） |
| `js/care.js` | お世話タイム（ごはん・おふろ・あそぶ／たまごは なでる・あたためる） |
| `js/state.js` | 保存・日付・育つ条件・九九の問題と苦手の記録 |
| `js/art.js` | キャラ（6なかま×あかちゃん/こども/おとな4タイプ）とたまごの絵 |

## 調整しやすい数字（`js/state.js`）

- `NEED`：次の姿に進む けいけんち。たまご20、あかちゃん80、こども150（1日に育つのは1だんかいまで。あまりは持ちこし）
- `PLAYS_PER_DAY`（3）、`CHALLENGE_SEC`（45）、`CARE_SEC`（60）、`CARE_MAX_ACTIONS`（2）

## きろくを消さないために（先生むけ）

- 記録はそのiPadのブラウザの中だけにある。iPadのSafariは、しばらく開かれなかったサイトの保存データを消すことがある（目安7日）
- **Safariの「共有」→「ホーム画面に追加」から開く**と、この消去の対象にならない
- 長い休みの前は、「せってい」→「ファイルに ほぞん」で書き出しておくと安心。消えたら「ファイルから もどす」（たまごえらびの画面では「きろくを もどす（せんせい）」）で戻せる
- 1台のiPadで持てるキャラは1ぴき（1人1台が前提）
